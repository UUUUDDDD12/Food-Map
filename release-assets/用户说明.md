# 食遇 v1.4.0 · 美食地图

支持 Windows 10 / 11，64位（x64）。完整解压后双击 **食遇.exe**，无需安装 Node.js。需要联网加载地图。

首次启动选择地图服务。高德需要你自己的 **Web端（JS API）Key** 和对应安全密钥，可在[高德开放平台](https://lbs.amap.com/api/javascript-api-v2/prerequisites)申请。可先选备用地图，之后从侧栏齿轮或托盘菜单进入“地图设置”。保存后返回地图立即应用，不需要重启程序。

安全密钥保存在你电脑的 `系统文件/data/map-settings.json`，不会回传到页面。Key是地图脚本所需的公开标识；不要把配置文件和个人数据再次公开上传。地图搜索消耗你自己账号的额度，程序不会自动进行批量采集。

发布包附带13,807家脱敏门店基础资料，首次启动自动创建自己的数据库，不附带作者的收藏、评价、打卡、上传照片或密钥。门店图片是公开来源链接，具体来源和使用说明见DATA_NOTICE.md。可在地图中“分享一家好店”，输入店名使用高德匹配，添加自己的门店。通过“数据库”入口查看和编辑；收藏的店默认展开，相邻店铺可在卡片内滚动查看；同点多个收藏分别展开，拖动卡片把手可移动位置。逐级放大地图可展开独立点和店名。点击打卡记录日期，再选1–3星；日期前的小垃圾桶可删除误打卡。

数据库和图片位于 `系统文件/data/`。关闭浏览器不会关闭后台服务；请从系统托盘中的食遇图标选择“退出食遇”，然后备份整个data目录。

程序只监听本机127.0.0.1，使用浏览器展示界面；不同电脑的数据独立保存。此版本没有公共账号、云同步或跨电脑共享评价。它不属于 GitHub Pages 静态网站。

这是未签名的开源便携版，Windows可能显示发行者提示。请从项目官方Release下载并核对SHA256文件。

完整图文教程：[使用指南](https://github.com/UUUUDDDD12/Food-Map/blob/main/docs/使用指南.md)。

## 可选API与功能限制

高德API和DeepSeek API均非必填。不配置时选备用地图即可浏览附带门店、筛选、收藏、打卡、评价和维护数据库；高德底图、地址搜索、添加新店的店名匹配需要高德Key，AI商圈更新需要同时配置高德和DeepSeek。

DeepSeek开放平台：https://platform.deepseek.com/ 。设置页右侧可填写官方API地址和密钥，选择 deepseek-v4-pro（默认）或 deepseek-flash，保存后回到地图点击对话图标。输入“更新沙河万达周边2公里的火锅”，选择准确商圈，地图会随每批入库刷新；对话不另开页面。

默认每轮最多2,000次高德调用；若扣除保留1,000次后不足2,000，按实际可用量执行，搜完即停。剩余次数为本机估算，请按控制台校正；其他应用消耗和跨月变化不会自动同步。模型与搜索调用使用自己的余额与额度，不保证全部收录或实时营业。模型只理解意图，不能编造门店写入库。

DeepSeek密钥保存在系统文件/data/ai-settings.json，升级时随整个data目录一起备份迁移，请勿公开。完整用法和限制见仓库README和图文指南。

## 个性化推荐

在地图内现有AI对话中问“推荐附近50元以内的店，清淡点，别重复最近吃过的”。助手结合自己的打卡星级、收藏与近期记录，默认避开近7天打卡店；介绍写在对话中，多家店同时在地图编号定位，点击可看详情。说“换几家”会避开上一轮推荐。

推荐查本地真实门店，不消耗高德搜索次数；配置DeepSeek后配合备用地图也能用。对话、自己的聚合偏好与少量候选资料会发给DeepSeek，不读取其他访客的打卡。健康需求仅供一般膳食选择参考，实际菜单、营养和过敏原未核实，不承诺疗效。
